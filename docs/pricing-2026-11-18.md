# November 18, 2026 pricing audit (0.2.13)

The shared catalog covers API-equivalent coding/text cost for Claude, Codex and
OpenCode. Subscription quota fetching, local usage retention and polling cadence
are unchanged.

## GPT-6.2 Astra and Sol

USD per million tokens, Standard tier:

| Model | Input | Output | Cache read | 30m cache write |
| --- | ---: | ---: | ---: | ---: |
| GPT-6.2 Astra, input ≤272K | 8 | 40 | 0.40 | 10 |
| GPT-6.2 Astra, input >272K | 16 | 60 | 0.80 | 20 |
| GPT-6.2 Sol, input ≤272K | 2 | 10 | 0.10 | 2.50 |
| GPT-6.2 Sol, input >272K | 4 | 15 | 0.20 | 5 |

Both general and Codex catalogs include these IDs and normal variant suffixes.
Fast/Priority is 2× Standard. Explicit Ultrafast is 3× through February 28,
2027 Pacific time, then 6× from March 1. The exclusive cutoff is
**2027-03-01T08:00:00Z** (March 1, 16:00 Asia/Shanghai), not midnight UTC.
The complete promotional entries are retained in `price_history`.
Codex lookup without a timestamp now uses the current time, matching the general
lookup, so it cannot skip an active promotion and use future list prices.

Sources: [OpenAI pricing](https://developers.openai.com/api/docs/pricing),
[Astra model](https://developers.openai.com/api/docs/models/gpt-6.2-astra),
[Sol model](https://developers.openai.com/api/docs/models/gpt-6.2-sol),
[November 17 release](https://developers.openai.com/api/docs/changelog).

The existing scanner has one unclassified GPT cache-write partition; it continues
using the 30-minute rate. Both legacy general-catalog write slots carry that rate;
they do not claim that OpenAI offers 5m/1h retention. Explicit 12-hour retention
cannot be inferred from these logs and is not newly implemented. Discounted
background completion windows, Batch/Flex and regional uplifts remain outside
the existing estimator. No unmarked request is assumed to use Ultrafast.

## Historical safety and verification

All previous `price_history` segments are retained without modification. Existing
model entries other than Qwen3.7 Plus are unchanged. Old Plus records keep the
complete former entry. Newly mapped IDs correct fallback estimates at their own
prices; no GPT-6 Astra/Sol or GPT-6.1 record is remapped to GPT-6.2.

Tests cover exact/variant matching in both catalogs, 272K and 256K boundaries,
cache partitions, CNY conversion, Standard/Fast/Ultrafast, the Pacific cutoff,
JSON round-trips, timestamp-free promotion lookup and earlier model prices.
The pricing fingerprint triggers the normal local rebuild; original logs and
previous caches are not deleted.

Regression result: 136 tests passed and two opt-in tests skipped when excluding
the pre-existing `testRepeatedControlClicksDoNotEndTrackedSubmenu` test. A full
run and isolated rerun reproduced only that test's two known assertions at
lines 389/391; its UI implementation is unchanged. The universal arm64/x86_64
release build passed, both slices retain macOS 13 minimum support, and the
locally installed bundle passed strict ad-hoc signature verification.
