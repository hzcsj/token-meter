# October 11, 2026 pricing audit

This update covers confirmed changes to the current coding/text-model catalog since the October 8 audit. Claude, Codex and OpenCode share the bundled price table. These are estimated API-equivalent costs, not subscription charges or Codex quota conversions.

## Updated mappings

Prices are USD per million tokens; standard on-demand API pricing unless a service tier is specified.

| Model / period | Input | Output | Cache read | Cache write |
| --- | ---: | ---: | ---: | ---: |
| GPT-6.1 Sol Ultrafast, ≤272K input tokens | 12 | 60 | 0.60 | 15 |
| GPT-6.1 Sol Ultrafast, >272K input tokens | 24 | 90 | 1.20 | 30 |
| Gemini 3.5 Flash, before October 8 | 1.50 | 9 | 0.15 | 1.50* |
| Gemini 3.5 Flash, October 8–December 31 | 0.75 | 3.75 | 0.075 | 0.75* |
| Gemini 3.5 Flash, from January 1, 2027 | 1.50 | 7.50 | 0.15 | 1.50* |

\* Gemini's cache-write slots use the existing input-price estimate for both durations. Time-based cache storage is excluded; these are not separately published 5m/1h write tariffs.

OpenAI's [October 8 changelog](https://developers.openai.com/api/docs/changelog) adds GPT-6.1 Sol Ultrafast. The [pricing table](https://developers.openai.com/api/docs/pricing) specifies 6× standard rates for all four token partitions, including long context. Only Codex records explicitly carrying `service_tier: "ultrafast"` use this multiplier. Standard and Fast/Priority are unchanged. Generic Claude/OpenCode pricing does not receive service-tier metadata, so it continues to use standard rates.

Google's [October 8 changelog](https://ai.google.dev/gemini-api/docs/changelog) and [Gemini 3.5 migration guide](https://ai.google.dev/gemini-api/docs/whats-new-gemini-3.5) say that all requests to `gemini-3.5-flash` now route to Gemini 3.6 Flash. The mapping therefore follows the replacement model's [published promotional and post-promotional prices](https://ai.google.dev/gemini-api/docs/pricing). Gemini 3.7 also routes to 3.8, but their existing catalog prices already match. Gemini 3.5 Flash-Lite is a separate model and is unchanged.

## Historical protection

- Complete previous Gemini 3.5 Flash and Codex GPT-6.1 Sol entries are added to `price_history` strictly before **2026-10-08 00:00 UTC**. Official sources give a date, not an exact billing instant; this follows the established date-only convention.
- A separate Gemini 3.5 promotional segment runs until **2027-01-01 00:00 UTC**, exclusive. Existing historical revisions are not overwritten.
- Pre-migration Gemini costs and pre-launch Sol tier estimates remain unchanged. Explicit Sol Ultrafast records from its launch and Gemini 3.5 records from its migration onward are corrected using event time, not cache-rebuild time.
- Catalog fingerprints refresh local cost caches automatically. Source logs, previous caches, quota behavior, authentication and user preferences are unchanged.
