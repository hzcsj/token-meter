# October 26, 2026 pricing audit

Checked the official sources for the existing coding/text catalog as part of the 0.2.10 release. Claude, Codex and OpenCode continue to share one bundled catalog. Costs are API-equivalent estimates, not subscription bills or quota conversions.

## Updated mapping

| Model / event time | Input | Output, including thinking | Implicit cache read |
| --- | ---: | ---: | ---: |
| Gemini 4 Argon, through November 30, 2026 | $2 | $10 | $0.10 |
| Gemini 4 Argon, from December 1, 2026 | $4 | $20 | $0.20 |

Prices are USD per million tokens at standard on-demand rates. Google's [pricing page](https://ai.google.dev/gemini-api/docs/pricing) publishes both periods. The [model page](https://ai.google.dev/gemini-api/docs/models/gemini-4-argon) confirms `gemini-4-argon` and implicit-only caching. There is no separate long-context price band. Explicit caching is unsupported; the catalog's generic cache-write fields use the normal input rate if normalized imported usage reports such tokens, not a separate published write tariff. Batch, Flex, Priority, Contributor, tool and storage charges remain outside this mapping.

The promotional entry ends exclusively at **2026-12-01 00:00 UTC**, following the existing date-only convention. It is selected using each usage event's timestamp, not the day the app rebuilds its cache. Existing current entries and prior history segments are untouched. Previously unrecognized Argon records now use their own prices instead of a fallback estimate.

This is not an exhaustive catalog of specialized audio/image/video models, legacy variants, regions, account discounts or every service tier. Prior estimation boundaries remain, including older Qwen multi-band estimates and the absence of distinct 12-hour OpenAI cache-write attribution in local Codex usage. Currency conversion remains 7 CNY per USD. The [October 11 audit](pricing-2026-10-11.md) and earlier audits retain historical context.

Every subsequent version update should recheck official pricing, including fix-only releases. Record no-change checks without rewriting the catalog; apply confirmed changes with complete historical entries. No automatic online pricing poll is added to the application.
